# 🚀 Como Executar o Projeto

Siga os passos abaixo para configurar e rodar o projeto localmente em sua máquina.

## 📋 Pré-requisitos

Antes de começar, certifique-se de ter instalado em sua máquina:
* **Node.js** (que inclui o NPM)
* **Android Studio** (com um emulador/simulador configurado)

---

## 🛠️ Passo a Passo para Execução

### 1. Instalar as dependências
Abra o terminal na raiz do projeto e instale todos os pacotes necessários:
```bash
npm install
```

### 2. Preparar o ambiente Android
1. Abra o **Android Studio**.
2. Inicialize o seu **Simulador (Emulador Android)** através do Device Manager.

### 3. Iniciar o servidor de desenvolvimento
Com o simulador já aberto, execute o Expo no seu terminal:
```bash
npx expo start
```

### 4. Autenticação no Expo
Quando o menu do Expo carregar no terminal:
1. **Escolha a forma de acesso:** Você pode logar com a sua conta do Expo ou entrar como anônimo.
2. **Navegação:** Use as **setas do teclado** (⬆️ ⬇️) para mover a seleção e a tecla **Enter** para confirmar.
